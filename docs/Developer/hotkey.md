# 快捷键触发

声明 [bmscriptsbox.triggers.shortcut] 即可为脚本绑定全局快捷键，无需编码。用户在盒子中为脚本预设快捷键后，按下快捷键启动时，盒子会根据声明自动注入选中的文件/文件夹路径及当前目录路径作为启动参数。


---

## 配置方式

```toml
[bmscriptsbox.triggers.shortcut]
enabled = true
input_type = "files"
filters = [".txt", ".md"]
```

## 字段说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `enabled` | 布尔值 | 否 | `false` | 是否启用快捷键 |
| `input_type` | 字符串 | 是 | — | 快捷键触发时获取的内容类型 |
| `filters` | 字符串数组 | 否 | `[]` | 文件扩展名白名单，规则同右键菜单 |

## input_type 可选值

| 值 | 获取的内容 | 适用场景 |
| --- | --- | --- |
| `"files"` | 当前选中的文件路径列表 | 批量处理文件 |
| `"folders"` | 当前选中的文件夹路径列表 | 批量处理文件夹 |
| `"active"` | 当前标签页的路径（单元素数组） | 以当前目录为工作区 |
| `"items"` | 选中的所有文件和文件夹 | 混合选择 |
| `""` | 空字符串、不传任何路径 | 不需要传参的脚本 |

## 关于按键组合

快捷键的具体按键组合（如 `ctrl+shift+f`）**不在配置文件中声明**。安装后，用户在盒子 UI 的「热键管理」页面自行设置。

流程：脚本安装成功后自动注册为"可设置快捷键的脚本"，用户进入热键管理页面即可绑定。若设定的组合已被其他脚本占用，盒子会自动解除原脚本的绑定，让新脚本获得该组合键。

---

## 常见问题

**Q：快捷键设置后不生效？**
A：检查：① `shortcut.enabled` 是否为 `true` ② 是否已在热键管理页面绑定按键 ③ 该组合键是否被其他脚本占用（后设置的会抢占）。
